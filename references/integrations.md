# 身体数据与日历：接入约定

本 skill 不内置健康账户或授权。部署时可接可用插件、当地设备日历或独立 WHOOP 官方 API 适配器，连接商可替换。每次执行先检查当前环境实际可用工具和授权，不能把设计能力说成已经接通。

## 无连接也可使用

接受用户自述精力、睡眠感受、近期活动，或用户主动提供的少量截图/摘要；接受手工空闲时段。无需上传完整健康导出或日历。数据不足时缩小结论，不编造恢复分。

## Apple Health

[Apple HealthKit 授权文档](https://developer.apple.com/documentation/healthkit/authorizing-access-to-health-data)说明按数据类型授权。实现需要支持 HealthKit 的应用/桥接读取后提供必要摘要；skill 文件本身无法直接访问手机 Health 数据。读取结果为空也不能据此断言用户拒绝授权或未产生数据。

未来桥接只请求当前用途需要的类型，例如睡眠、近期运动、静息心率和 HRV。保留采样时间、单位、数据来源和同步状态；不把 Apple Health 当成统一恢复评分服务。

## WHOOP

[官方 API v2](https://developer.whoop.com/api/)提供 OAuth 2.0 和 recovery、sleep、cycles、workout 数据。先查看实际连接器是否存在；没有时明确尚需实现，不能虚构工具名。

按功能申请最少 scope：read:recovery；需要时增加 read:sleep、read:cycles 或 read:workout。凭据由连接服务管理，不放入 skill、聊天或记忆文件。检查 score_state、校准状态、日期和分页，缺失/尚未评分不能当作零分。设备数据仅作辅助线索，没有验证过的「某恢复分→某课程」处方。

## 日历

优先只取目标日期的 free/busy，避免读取无关标题、参与者和正文。用户指定的日历范围不扩大为所有账户。未接通或范围不完整时明确尚未完成完整冲突核查；只有确实提供并检查了具体时段，才说该范围内无冲突。

所有事件转换为明确时区的起止时间；包括跨日、全天、重复事件例外。占用区间包含抵达、现场登记、课程及离开/转场缓冲；具体缓冲来自场馆规则与用户实际安排，未知时明示假设。两个半开区间 [a,b)、[c,d) 的冲突条件是 a<d 且 c<b。

创建日历需要用户对所选场次的指令；既有明确授权无需重复询问。创建前复查课表和忙闲，展示明确场次、日期、时区及缓冲，避免重复创建。未拿到成功结果不能声称写入成功；没有写入工具可应要求生成待导入文件，并标为未导入。日历写入不等于 Yoga Barn 报名。

## 数据边界

授权读取不自动包含长期保存、分享给场馆或用于研究。说明实际处理路径；本地桥接若把摘要送给云端模型就不是本地推理。允许拒绝、撤销和回退到自述选课，断开后不继续读取。

## 接入验收及降级

分开报告安装、账户登录、数据源授权、同步、实际读取五种状态；安装插件不等于健康数据已经接通。WHOOP 必须读到带实际采样日期和评分状态的数据才能报告读取成功。服务候补/满额时明确阻塞，不虚构授权入口，不绕过服务限制。

Apple Calendar 可通过当前环境支持的本机访问路径读取；它只代表这台设备已同步且可访问的日历，不代表手机、云端或其他用户自动拥有同样权限。验证目标日期和时区、日历范围、重复事件及全天事件后才能声明冲突检查完整。订阅节日或待定提醒不自动等于全天忙碌；发生疑义时询问用户。写入课程和读取忙闲分别授权，不为测试擅自创建日程。

原始账户信息、令牌和个体健康/日程不进入共享 skill。健康摘要被发送给云端模型时明确它不是全程本地推理。

## 本机个人适配器发现与复用

跨 session 先检查现有适配器，不要求用户粘贴接入路径。本机试用约定：项目目录取环境变量 `YOGA_BARN_HOME`，未设置时检查 `~/Desktop/Yoga_Barn`；仅在存在 `scripts/whoop_local.py` 时使用。它是该用户的本机试用适配器，不是所有安装者都拥有的服务。没有该文件则检查可用连接器，仍无则降级。

先运行适配器 `status`。`authorized:true` 时运行 `summary` 获取当前真实摘要；历史验证成功不替代本次读取成功。不要读取或打印凭据文件。`authorized:false` 的历史错误可能早于当前连接尝试，不据此反复重启服务；不要重放浏览器 callback URL 或旧授权链接。`summary` 失败时报告本次读取不可用，不自动要求重新授权。首次连接和刷新功能的状态应分别验证。

苹果日历使用本机当前可用的日历工具，按目标日期检查实际可读性。跨任务不能仅凭曾经可读就报告本次无冲突。新安装者的连接与授权不继承其他用户的状态；不把任何个人 client id、凭据或日历内容打包进共享 skill。

## 新鲜度与发布边界

同一次选课可复用刚读取的数据，同时区分读取时间和记录更新时间；最新一条记录不自动属于今天，应核对当地日期和关联cycle。进行中的活动负荷可能滞后，不能称为实时值。睡眠起止间隔不等于实际睡眠时长。只展示影响判断的指标，不堆砌HRV或心率营造精确匹配。

日历范围不完整就说尚未完成完整冲突核查；只有确实提供并检查了具体时段才能说该范围无冲突。用户忽略大会仅作用于指定事件/日期，不自动忽略其他事件。未确认全天占用作为明确条件，不反复打断。

当前共享包不包含通用安装即用的WHOOP OAuth服务或Apple Health桥接。本机适配器和系统授权不随skill分发；本机成功不是新用户验收。发布前仍需独立验证新用户首次连接、令牌刷新、撤销/断连、故障恢复和无设备降级，未完成应标明本机试用能力。
