## 入门解释

以下为 S1 官方课程目录的简短释义；具体场次优先。这些是课程形式，不是为不同身体状态开的处方：

| 类型 | 主要体验 |
|---|---|
| Vinyasa | 呼吸配合连续体式转换 |
| Hatha | 更注重停留与动作对齐 |
| Power | 动态练习和更具挑战的保持 |
| Yin | 较长时间停留于地面体式 |
| Restorative | 借助支撑道具休息 |
| Beginner’s Yoga | 逐步讲解基础动作 |
| Yoga Nidra | 引导式放松 |
| Pilates / PiYo | 肌肉控制；PiYo 混合多种练习 |
| Kundalini | 动作与呼吸结合 |
| Sound Healing | 声音与聆听体验 |
| Ecstatic Dance | 音乐下自由舞动 |
| Kirtan | 集体回应式唱诵 |
| AcroYoga / Fly High | 双人配合／悬挂辅助体验 |

分类不是个人适用性判定。进一步区分呼吸练习是否包含快速呼吸或屏息、是否有身体接触、声音强度及教学方式；未知时不推测。

## 报名与时间

FAQ 在核查时说明：常规课为现场 drop-in，开课前 30 分钟在前台开放登记，先到先得，当时不提供 App/网上提前订课；工作坊、retreat 和培训另有预订流程。因而计划应考虑登记时间，不能只比较课堂起止。未来如官方变更，以新规则为准；余位未确认时提供备选，不保证入场。

晚课登记、Ecstatic Dance 票务是例外，按 official-selection.md 核对，不把 FAQ 的 30 分钟规则扩大到所有项目。

## 动态课表读取经验（2026-09-17 实测）

官网逐日课表可读取。初次打开页面的文本树可能只有课程目录；不要据此断言课表不可用。使用浏览器打开课程页，点击页内 Schedule（#schedule），再读取更新后的页面，等待动态 Mindbody 课表出现 FIND A CLASS、日期选择和具体场次。点击每个场次 View details 可取得场地、该场次内容、参与要求与登记说明。核对日期及+08时区，不把首次未加载完成当成官网没有课表。
