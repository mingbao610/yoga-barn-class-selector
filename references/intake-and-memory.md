# 提问与用户偏好记忆

问卷是助手依据官网课程差异设计的，不是场馆官方问卷。来源见 official-selection.md：Beginner’s明确更多基础示范/调整时间；Open Level不承诺相同指导；课程形式包含动作、静态休息、声音、舞蹈等。

## 选择问题：唯一入口规则

先列出已知信息与缺口，不从模板反推用户需要回答什么。每次推荐前总计最多三题，每题一个决策维度；只用缺失字段，不自动凑满。

1. 首次接入意愿未知：保留一题可选连接。未连接或跳过不影响基础推荐。
2. 其余名额优先解决让推荐不可用的歧义（目标日期/时间、相关参与条件）；否则补练习经验与所需指导。
3. 剩余名额用于本次体验目标/当天感受；若请求已明确目标与感受则跳过，转问未知的课卡费用偏好。阶段目标仅在多日规划或用户主动提及时问，不作为每次首次选课的必填项。
4. 有名额且课卡偏好未知时问课卡范围。没有名额则按事实标注各候选费用，不假装用户接受额外付费，也不新增隐藏第四题。

这意味着全新用户的三题不能收集所有字段；未问到的字段保持未知，推荐说明相关条件。不要重复追问、不猜答案。用户明确要求追加某一题时可补问，但不改变其他用户的默认上限。

| 情况 | 提问示例 |
|---|---|
| 全新用户只说帮选今天的课 | 经验、今天想怎样参与、可选连接 |
| 用户说今天状态好想充分活动，经验与连接未知 | 经验、可选连接、课卡范围 |
| 经验和连接已知，今天需求与费用偏好未知 | 当天参与、课卡范围 |
| 经验、课卡、连接已知，已说今天想上什么 | 不重复提问；仅有会影响结果的缺口时补问 |
| 刚推荐完，问前台在哪里或英语怎么说 | 零问卷，直接回答 |

## 题库与自由回答

每题提供快捷选项和自由输入；自由描述可替代选择，冲突时以明确的自述为准。不预选、不从无回答推断默认意愿。用户可直接在对话中说跳过。选项根据当前环境改写；不要把单选叫多选。

**经验与指导**：「基础瑜伽动作，你熟悉到什么程度？」
- 还没学过，希望从头讲解
- 上过一些课，仍需要示范和纠正
- 熟悉基础动作，能跟随连续练习
- 有持续或深入练习经验

不以年限、倒立能力分官方等级，不从经验推体能，不把熟悉地面体式扩展为空中/双人技能。

**本次参与**：「今天更想怎样参与？」
- 状态不错，想充分活动
- 想适量活动，留些余力
- 比较疲惫，想以休息为主
- 还没想好，先看备选

自由输入接受其他活动形式、不适和限制，不额外要求完整病史；不用WHOOP替用户回答。不自动把积极参与映射到高强度。

**课卡范围**：「选课时，要限定在 Yoga Barn 课卡可用的课程吗？」
- 只看课卡可用的课，不额外付费
- 优先用课卡，特别想上的课可另付费
- 不限课卡范围，注明价格即可
- 还不确定，先说明区别

可自愿补充卡种/单次预算，但不额外必问。不从选择推断已经持卡、余额或有效期。未确定则先解释官网费用类别，不代选。

**可选连接**：「这次选课，你愿意连接哪些数据？」
- 先不连接，直接选课
- 苹果日历
- WHOOP
- 日历和身体数据（可自由写组合）

仅列实际可用的来源；Apple Health有可用桥接时才作为可连接选项，否则说明暂不可接。完全无接入能力时将此题改为可选意愿说明，不让用户走无效授权流程，名额用于选课。

题前简述：日历用于避冲突，身体数据作补充；均可跳过，必要摘要会用于当前云端对话。选择是接入意愿，不等于服务商授权或实际读取成功；进入接入后仅处理相应来源的必要登录/授权，不借此加画像题。有有效授权不重走；不连接不反复推销。

**阶段目标（多日规划）**：「这段时间在 Yoga Barn，你希望收获什么？」选项可为建立基础、持续练习、安静专注、探索音乐舞蹈、先尝试不同方向。阶段期限未知不猜；不把当天目标升级为长期目标。

## 显示与回传

按SKILL.md选择内联表单或降级方式。assets/intake-form.html的题目仅为接入/目标已知的示例；生成前必须替换成此次选中的题目。表单不设自动消失计时，无宿主发送能力时提供可复制文本。实际收到用户消息才认为提交成功，不以工具accepted或发送入口返回代替。不要为显示故障再次要求WHOOP授权。

## 个人记忆

优先使用当前用户已授权且真实可读写的个人记忆服务。否则可用单用户文件：macOS `~/Library/Application Support/YogaBarnGuide/preferences.json`；其他系统 `${XDG_DATA_HOME:-~/.local/share}/yoga-barn-class-selector/preferences.json`。目录0700、文件0600，先读最新版再合并并原子替换；共享系统按已验证用户身份隔离。凭据不进入偏好文件。

只有用户已要求记住或已有适用授权时写入。新用户回答问卷不自动授权跨任务保存；可在结果中简短说明回复「记住偏好」后可复用，不强加额外一题。无持久化能力就说明只在本次对话复用。

schema_version为1，包含updated_at和fields。每个字段包含value、reported_at、source:user_report；payment_preference使用card_only/card_preferred/any/unsure并可附user_wording。可保存experience、guidance_preference、familiar_styles、experience_preferences、payment_preference和明确的period_goal。阶段目标另记scope:stay|period、valid_until（未知null）。授权依据来自真实对话/个人记录，不嵌入共享skill。

稳定字段已知则复用，用户纠正即更新。单次允许额外付费不自动覆盖长期card_only。过期阶段目标不可继续当作有效；当日精力、疼痛、设备读数和日程默认仅供本次使用，不写成长远画像。只写实际答案，未知字段缺省，不能写样例或推断等级。

写入后验证可读性、字段和权限再说记住。用户要求忘记时删除对应偏好，不触碰凭据。安装skill不会生成用户档案，也不会自动跨设备同步。
